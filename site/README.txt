PRIMECORE TECHNOLOGIES LIMITED — WEBSITE DESIGN REVIEW COPY
============================================================

WHAT THIS IS
A complete, offline copy of the Primecore Technologies Limited website design,
captured page by page from the live build. It needs no internet connection and
no server: open index.html in any browser and the whole site works from your
own computer.

HOW TO OPEN IT
1. Unzip this folder somewhere on your computer (e.g. Desktop).
2. Double-click index.html — it opens in your browser.
3. Use the navigation to move between pages, exactly as on the live site.

WHAT TO KEEP IN MIND
This is a review copy, not the deployed product. It was captured as static
pages, so a few things that need a live server or JavaScript are dormant here:

  • The quotation form, contact form and newsletter form display correctly but
    do not submit from this offline copy. On the deployed site they validate,
    confirm, and compose the enquiry to primecoretechno@gmail.com.
  • Catalogue filtering, the enquiry basket, the site-wide search overlay, the
    FAQ accordion and the testimonial slider are static here.
  • The admin dashboard sign-in is a front-end demonstration only. Real user
    accounts and server-side authentication must be added before the site goes
    live, and no content changes should be treated as permanent until then.
  • Mobile navigation, the floating WhatsApp button, click-to-call and
    click-to-email links work normally.
